# GeoPulse: Hyper-Local Retail Mobility Analytics

## Project Overview

GeoPulse is a Data Analytics project focused on
analyzing pedestrian mobility patterns to identify
high-traffic locations and understand retail
opportunities.

## Internship Details

- Company: Infotact Solutions
- Role: Data Associate L1 Intern
- Domain: Data Analytics

## Project Objectives

- Collect and understand pedestrian datasets.
- Clean and validate the data.
- Perform exploratory data analysis.
- Identify pedestrian traffic patterns.
- Develop interactive dashboards.
- Generate actionable business insights.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit
